## 📦 Getting Started Locally

### Prerequisites
- Node.js (v20+ recommended)
- [pnpm](https://pnpm.io/) (v9+)

### Installation & Run
```bash
# 1. Clone the repository
git clone https://github.com/thtcsec/thtcsec.github.io.git
cd thtcsec.github.io

# 2. Install dependencies with pnpm
pnpm install

# 3. Start development server
pnpm run dev

# 4. Build and run static pre-rendering
pnpm run build
```
